# EpiContext 文献与问题文档

## 相关工作分类

### 1. Agent记忆管理

#### 1.1 短期记忆管理
- **ReAct** (Yao et al., 2023): Thought-Action-Observation循环，基础Agent架构
- **Reflexion** (Shinn et al., 2023): 通过自我反思增强记忆
- **Chain-of-Thought** (Wei et al., 2022): 推理链增强

#### 1.2 长期记忆管理
- **MemGPT** (Packer et al., 2023): 操作系统式分层记忆管理
- **MemoryBank** (Zhong et al., 2024): 基于Ebbinghaus遗忘曲线的记忆更新
- **A-MEM** (Xu et al., 2025): 基于Zettelkasten的Agentic Memory
- **ProMem** (Chen et al., 2025): 主动记忆提取，解决信息缺失积累
- **LightMem** (Sinha et al., 2025): 轻量级SLM记忆管理

#### 1.3 记忆压缩
- **Generative Agents** (Park et al., 2023): 分层摘要策略
- **Summarized Memory**: 对话历史压缩
- **Mem0**: 生产级记忆层

### 2. 上下文窗口优化

#### 2.1 上下文压缩
- **Lost in the Middle** (Liu et al., 2024): 长上下文中的信息丢失
- **Context Engineering** (Anthropic, 2025): 有效的上下文工程实践
- **Dynamic Context Discovery** (Cursor, 2025): 动态上下文发现

#### 2.2 选择性上下文
- **Selective Context**: 基于相关性的上下文选择
- **RAG** (Lewis et al., 2020): 检索增强生成
- **AutoTool** (Zhang et al., 2025): 动态工具选择

### 3. 工具管理

- **Toolformer** (Schick et al., 2023): 工具学习
- **AutoTool**: 动态工具选择和集成
- **MCP** (Model Context Protocol): 工具标准化

### 4. 生物学启发AI

- **Epigenetics in AI**: 主要用于生物信息学（DNA甲基化预测等）
- **Neuroscience-inspired AI**: 神经科学启发的AI架构
- **Evolutionary Algorithms**: 进化算法在优化中的应用

## 审稿人潜在问题与防御

### 问题1: 表观遗传学隐喻是否必要？
**防御**: 
- 隐喻提供了系统性的理论框架
- 甲基化/乙酰化概念直观且可量化
- 与现有方法形成明确区分

### 问题2: 与现有记忆管理方法的区别？
**防御**:
- 现有方法多为静态/半静态，EpiContext是动态进化的
- 联合优化记忆和工具，而非分别处理
- 引入适应度反馈循环

### 问题3: 实验规模是否足够？
**防御**:
- 4个基准数据集，涵盖多种任务类型
- 消融实验验证各组件贡献
- 统计显著性检验

### 问题4: 是否对特定LLM有依赖？
**防御**:
- 框架与LLM无关，可应用于任何LLM
- 实验使用多种LLM验证通用性

### 问题5: 计算开销？
**防御**:
- 上下文选择的开销远小于Token节省
- 实验报告实际运行时间
- 提供计算效率分析
