# EpiContext 实验构想文档

## 实验目标

验证EpiContext框架在以下方面的有效性：
1. 任务成功率提升
2. Token效率优化
3. 长程任务中的信息保持能力
4. 消融实验验证各组件贡献

## 实验设计

### 基准数据集

1. **WebArena** (Zhou et al., 2023)
   - 类型: 网页交互任务
   - 规模: 812个任务
   - 特点: 需要多步推理和工具使用

2. **SWE-bench Lite** (Jimenez et al., 2024)
   - 类型: 软件工程任务
   - 规模: 300个任务
   - 特点: 需要代码理解和工具调用

3. **AgentBench** (Liu et al., 2023)
   - 类型: 多领域Agent任务
   - 规模: 1000+ 任务
   - 特点: 涵盖多种任务类型

4. **ALFWorld** (Shridhar et al., 2021)
   - 类型: 家庭环境文本游戏
   - 规模: 250个任务
   - 特点: 长程决策和状态跟踪

### 基线方法

1. **ReAct** (Yao et al., 2023): 基础Thought-Action-Observation循环
2. **Reflexion** (Shinn et al., 2023): 反思增强的ReAct
3. **MemGPT** (Packer et al., 2023): 操作系统式记忆管理
4. **AutoTool** (Zhang et al., 2025): 动态工具选择
5. **Full-Context**: 无优化的完整上下文基线

### 评估指标

1. **任务成功率 (Success Rate)**: 成功完成任务的比例
2. **Token消耗 (Token Usage)**: 完成任务所需的总Token数
3. **信息密度 (Information Density)**: 有效决策/总Token比例
4. **平均步数 (Average Steps)**: 完成任务所需的平均交互轮数
5. **上下文压缩率 (Compression Ratio)**: 原始上下文/压缩后上下文

### 实验协议

#### 实验1: 主实验 - 任务成功率与Token效率
- 在4个基准上运行EpiContext和5个基线
- 每个任务重复3次取平均
- 记录成功率、Token消耗、步数

#### 实验2: 消融实验
- **w/o Methylation**: 移除记忆甲基化机制
- **w/o Acetylation**: 移除工具乙酰化机制
- **w/o Crossover**: 移除交叉重组机制
- **w/o Fitness**: 移除适应度反馈
- 验证各组件的必要性

#### 实验3: 长程任务性能
- 在ALFWorld上测试不同任务长度（10/20/50/100步）
- 比较EpiContext与基线的性能衰减

#### 实验4: 工具数量敏感性
- 测试不同工具数量（5/10/20/50个）
- 验证工具乙酰化的有效性

#### 实验5: 适应度函数分析
- 分析不同α/β/γ参数设置的影响
- 可视化适应度随任务推进的变化

### 超参数设置

- **甲基化阈值**: Token数 > 4000时触发
- **乙酰化阈值**: 相关性分数 < 0.3时移除工具
- **交叉重组触发**: 连续3次报错
- **适应度参数**: α=1.0, β=0.5, γ=0.3

### 统计显著性

- 使用配对t检验比较EpiContext与最佳基线
- 显著性水平: p < 0.05
- 报告95%置信区间

## 预期结果

1. EpiContext在保持或提升任务成功率的同时，显著降低Token消耗（预期降低30-50%）
2. 消融实验显示各组件均有正向贡献
3. 长程任务中EpiContext性能衰减更慢
4. 工具数量增加时，EpiContext优势更明显
